#### Developer instructions:

##### Make sure you have the following installed:

* **Node.js** ≥ 20
* **npm** (comes with Node.js)
* **Git**

##### Clone the repository and install dependencies:

```
git clone https://github.com/mcxzrs/ustp-cicd-final.git
cd ustp-cicd-final
npm ci
```

##### Run the tests and run the application
(add npm run test:coverage if you want to see code measurement)

```
npm run test
npm run dev
```

##### Build the application

```
npm run build
```
